## ✨ Features

- 💜 **Unified Purple Liquid Glass Design**: Vibrant glassmorphic cards, glowing borders, custom backdrop filters, and subtle ambient light orbs.
- 💻 **Interactive Fedora CLI Terminal Modal**:
  - Live system status & `git jan doctor` repository health diagnostic.
  - Functional window control dots: 🔴 Close (Esc), 🟡 Clear/Reset, 🟣 Fullscreen Toggle.
  - Slanted monospaced ASCII logo banner with custom terminal prompt commands (`help`, `clear`, `contact`, `skills`, `projects`, `health`).
- ⚡ **Optimized Performance & UX**:
  - Responsive single-page layout with smooth navigation.
  - Inertia-free smooth scrolling powered by Lenis.
  - Zero cutoff on mobile and desktop viewports.
- 🚀 **Automated CI/CD Deployment**:
  - Fully automated GitHub Actions workflow (`.github/workflows/deploy.yml`) publishing directly to custom domain `peaush.is-a.dev`.

## 🛠️ Technology Stack

- **Framework**: [Astro 7](https://astro.build/) (Static Site Generation)
- **Styling**: Tailwind CSS + Custom CSS Variables & Glassmorphism Utilities
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: Lucide Icons
- **Domain**: [peaush.is-a.dev](https://peaush.is-a.dev/)
- **Deployment**: GitHub Pages (Actions)

## 🚀 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/peaush07/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle
npm run build
```
